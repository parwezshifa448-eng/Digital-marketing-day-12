### 2. The 3-Step Search Pipeline Architecture
Search engine kisi bhi website ko mukhyata 3 steps mein process karta hai[span_3](start_span)[span_3](end_span)[span_4](start_span)[span_4](end_span):

* **Step 1: Crawling (Khojbeen)**
  * **Executing Agent:** Googlebot / Spider / Bot[span_5](start_span)[span_5](end_span)
  * **Primary Function:** Yeh World Wide Web (WWW) par ghoom kar naye ya updated web pages aur links ko discover karta hai aur raw data ko **Local Server** par dump kar deta hai[span_6](start_span)[span_6](end_span)[span_7](start_span)[span_7](end_span)[span_8](start_span)[span_8](end_span).
* **Step 2: Indexing (Library Bahi-Khata)**
  * **Executing Agent:** Indexer Engine[span_9](start_span)[span_9](end_span)
  * **Primary Function:** Local Server ke raw data ko analyze karke alag-alag categories (jaise Tech, News, Images) mein sort karta hai aur **Main Server Index** (Structured Database) mein store karta hai[span_10](start_span)[span_10](end_span)[span_11](start_span)[span_11](end_span)[span_12](start_span)[span_12](end_span).
* **Step 3: Ranking (Nateeja & SERP Display)**
  * **Executing Agent:** Ranking Algorithms[span_13](start_span)[span_13](end_span)
  * **Primary Function:** User ki query aane par 200+ ranking factors (jaise E-E-A-T, Content Quality, Backlinks) ke aadhar par sabse best page ko SERP (Search Engine Results Page) par top position par dikhata hai[span_14](start_span)[span_14](end_span).

### 3. Webmaster Control Levers (Crawling & Indexing Control)
Website ko sahi tarike se search engine mein laane ke liye ye 3 mukhya tools use hote hain[span_15](start_span)[span_15](end_span):
* **Robots.txt:** Is file ke zariye crawler ko instructions di jaati hain ki website ke kis part ko crawl karna hai aur kise block karna hai[span_16](start_span)[span_16](end_span).
* **XML Sitemap:** Yeh website ke sabhi important URLs ki ek map list hoti hai jo crawler ko naye pages jaldi dhundne mein madad kart کرتی hai[span_17](start_span)[span_17](end_span).
* **Google Search Console (GSC):** Webmasters iska use karke URL inspection tool ke zariye Googlebot ko manual crawling request bhej sakte hain[span_18](start_span)[span_18](end_span).
